Sources & data

OpenLiDAR — Last updated: August 2026 · Language: English.

OpenLiDAR is a side-by-side LiDAR / DTM relief viewer, 100% client-side, no account, no API key. The app is an aggregator of public data: it does not host, own or modify the underlying datasets. Relief, imagery and geocoding are fetched live from the public services listed below. Each licence sets how that source may be used and attributed; where a source requires a credit line, it is shown in the map's attribution control and reproduced here.

Attribution & licensing notes

  • OSM / ODbL: attribution to OpenStreetMap contributors and a link to openstreetmap.org/copyright is kept visible on the map, as required by the OSM Foundation attribution guidelines.
  • IGN / LICENCE OUVERTE 2.0: reuse requires acknowledging the source (IGN) and the date of the most recent update, and allowing consultation of the licence online — both done here.
  • Environment Agency / OGL v3.0: credit "Contains Environment Agency information © Environment Agency and/or database right".
  • The app never stores, redistributes or serves as an intermediary for these datasets; it only requests tiles directly from the providers. Please respect each provider's fair-use and rate limits.
